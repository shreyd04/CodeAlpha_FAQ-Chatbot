# CodeAlpha_FAQ-Chatbot

An NLP-powered Chatbot that utilizes **TF-IDF Vectorization** and **Cosine Similarity** to match user questions with predefined FAQs.

## Features
- NLP text preprocessing using **NLTK** (Tokenization, Lowercasing, Stopword removal, Lemmatization).
- Intent matching using **Scikit-Learn** TF-IDF and Cosine Similarity algorithms.
- Full conversational user UI built with **Streamlit Chat**.
- Fallback response handling when confidence thresholds aren't met.
